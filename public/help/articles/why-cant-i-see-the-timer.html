Why can't I see the timer?

Last updated November 2026

The timer lives on one page, so it is easy to miss. Work through these checks in order.

1. Open the Time page

Click Time in the left-hand menu. The timer is the card at the top of the page, with a box for what you are working on, a project list and the Start timer button.

2. Look for the running badge

While a timer is running, a Timer running badge appears at the top right of every page, next to your name. Click it to jump back to the timer.

3. Check the project list

The timer only lists projects that are not finished. If the project you want is in the Done stage, move it back to Review or In progress first.

4. Still nothing?

Reload the page. If you opened Roozfir in a private window, your timer is kept in that window only.
