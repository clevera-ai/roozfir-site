Start your first project

Last updated November 2026

A project is where your time and invoices for one piece of work come together. Here is how to start your first one.

  1. Click Projects in the left-hand menu. Then click Start new project at the top right.
  2. Type a Project name and choose the Account (your customer) from the list.
  3. A Billing contact box appears once you have chosen an account. Type the person who should receive the invoices. It is required.
  4. If you like, add a Budget. Roozfir warns you as the money runs out.
  5. Click Create project. Saving takes a few seconds and the button shows a spinner while it works. Please wait for the message "Created Spring campaign" before you close the page.
  6. The new project appears in the list with the stage "Planned".

You can also create a project in three steps with the guided setup. See Create a project with the wizard.
