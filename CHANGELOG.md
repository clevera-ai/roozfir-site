# Changelog

## v1.3 - 2026-11-07

Clearer button labels

- "Start timer" and "Stop timer" are now "Start tracking" and "Stop tracking".
- "New invoice" is now "Create invoice", and "Send invoice" is now "Send to client".
- "New project" is now "Add project".
- "Invite teammate" is now "Invite someone".
- "Save profile" is now "Save changes".
- "Change plan" is now "Switch plan".

## v1.2 - 2026-11-07

Clients are now Customers, under Contacts

- "Clients" is now called "Customers" everywhere in Roozfir, including buttons, forms and reports.
- Customers moved into a new "Contacts" menu in the sidebar.

## v1.1 - 2026-11-07

Track expenses on projects

- Projects now have an Expenses section. Add an expense with a description, amount and date, and mark it billable to the client.

## v1.0 - 2026-11-07

Roozfir 1.0

- Track time with a one-click timer, weekly timesheets and bulk edits.
- Create invoices from tracked time, or set up recurring invoice schedules.
- Keep clients, projects and a drag-and-drop stage board in one place.
- Build automation rules, invite your team and set permissions per role.
